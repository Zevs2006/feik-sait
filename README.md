# ВОЛЬТ — учебный интернет-магазин электроники

Полноценное веб-приложение интернет-магазина на PHP 8 и SQLite, подготовленное для практического занятия по тестированию веб-приложений. Витрина, каталог, корзина, оформление заказа, личный кабинет и административная панель работают как единая система.

> Проект предназначен для изолированной учебной среды. Не используйте его как production-приложение.

## Быстрый запуск

### Требования

- PHP 8.1 или новее;
- включённые расширения `pdo_sqlite` и `mbstring`;
- любой современный браузер;
- никаких внешних сервисов и платных зависимостей.

Проверить расширения можно командой:

```bash
php -m
```

В списке должны быть `PDO`, `pdo_sqlite`, `sqlite3` (необязательно), `mbstring`.

### Windows

```bat
cd voltmarket\public
php -S localhost:8000
```

Или запустите `start.bat` из корня проекта.

### Linux / macOS

```bash
cd voltmarket/public
php -S localhost:8000
```

Или:

```bash
chmod +x start.sh
./start.sh
```

После запуска откройте:

**http://localhost:8000**

Альтернативный запуск из корня проекта:

```bash
php -S localhost:8000 -t public
```

> Важно: точкой входа должен быть каталог `public`, а не корень проекта. Файлы базы данных, конфигурации и материалы преподавателя не должны быть доступны по HTTP.

## База данных

SQLite-база создаётся автоматически при первом запросе:

- файл: `database/voltmarket.sqlite`;
- схема: `database/schema.sql`;
- демонстрационные товары и категории: `database/seed.sql`;
- пользователи и тестовые заказы создаются при инициализации из PHP.

Данные для входа и тестовые заказы создаются только при первичной инициализации. Чтобы вернуть приложение в исходное состояние:

1. остановите PHP-сервер;
2. удалите `database/voltmarket.sqlite`, а также файлы `database/voltmarket.sqlite-wal` и `database/voltmarket.sqlite-shm`, если они есть;
3. снова запустите сервер и откройте сайт.

База создастся заново и заполнится демонстрационными данными.

### Пользователи

## Настройка PHP

Если `pdo_sqlite` не подключён, включите его в `php.ini`:

```ini
extension=pdo_sqlite
extension=mbstring
```

Для XAMPP можно использовать `C:\xampp\php\php.ini`. После изменения `php.ini` перезапустите PHP.

Если при запуске отображается ошибка о невозможности открыть файл сессии, убедитесь, что каталог `storage/` доступен для записи. Приложение хранит сессии в `storage/sessions`.

## Если вместо сайта открывается «Not Found» или ошибка 500

### «Not Found» на главной

Почти всегда это означает, что PHP-сервер запущен из корня проекта, а не из `public`. В корне намеренно нет `index.php`, поэтому `http://localhost:8000/` не находит точку входа.

Остановите сервер (Ctrl+C) и запустите его одним из способов:

```bat
cd C:\путь\к\voltmarket\public
C:\xampp\php\php.exe -S localhost:8000
```

или из корня проекта:

```bat
cd C:\путь\к\voltmarket
php -S localhost:8000 -t public
```

Можно также запустить `start.bat` из корня проекта. Он сам переходит в `public` и использует PHP из XAMPP, если тот установлен.

> Не оставляйте PHP-сервер запущенным из корня проекта: в этом случае по HTTP становятся доступны `README.md` и `TEACHER_BUG_LIST.md`.

### Ошибка 500 / «could not find driver»

У выбранной версии PHP не включён драйвер SQLite. Проверьте:

```bash
php -m
```

В списке должны быть `pdo_sqlite` и `mbstring`. Если их нет, используйте PHP из XAMPP:

```bat
C:\xampp\php\php.exe -S localhost:8000
```

Запускать команду нужно из каталога `public`.

### Порт 8000 уже занят

Остановите предыдущий PHP-сервер (Ctrl+C) или запустите на другом порту:

```bash
php -S localhost:8001
```

и откройте `http://localhost:8001`.


## Технические решения

- **PDO + SQLite** — единая точка доступа к данным, подготовленные запросы;
- **сессии PHP** — авторизация, CSRF-токены, корзина гостя;
- **корзина в БД** — таблица `cart_items`, отдельные ключи для гостя и пользователя;
- **снимки цен в заказе** — `order_items.unit_price` сохраняет цену на момент покупки;
- **CSRF-защита** — все изменяющие POST-запросы проверяют токен;
- **разделение ролей** — административные разделы защищены проверкой роли;
- **локальные ресурсы** — все изображения и шрифтовые настройки работают без интернета.

## Ограничения

- приложение работает только локально;
- платежи, доставка и email-уведомления имитируются;
- SQLite выбран для простоты развёртывания и не рассчитан на высокую конкурентную нагрузку;
- проект не является production-системой и не должен использоваться для реальных заказов.
